# Flutter Manager 界面规范

本次以 ui-ux-pro-max 的扁平化、语义配色、Flutter 自适应布局建议为参考，结合桌面开发工具的实际操作密度整理。保留浅色、深色和跟随系统，不套用营销落地页结构或强制深色模式。

## 色彩与层级

- 主色蓝：导航定位、主要操作、FVM 与 Flutter 环境。
- 青绿：项目管理、运行调试、环境就绪状态。
- 琥珀：安装包、缓存、构建相关信息；危险操作仍使用错误红色。
- 紫色：MCP / AI 接入。
- 导航栏在两种主题下保持深蓝底，内容区使用独立的主题表面色。
- 前景与背景通过 ColorScheme / AppPalette 统一维护，不在业务页面复制十六进制色值。
- 状态同时提供文字或图标，不能只靠颜色表达。

## 布局与组件

- 固定主导航、顶部当前位置、页面标题、工作区形成四层结构。
- 全局页面边距 24，模块间距 16 / 24；控件圆角 8、卡片 12、对话框 16。
- 页面标题和操作区在宽窗口横向排列；窄窗口允许操作区换行，主操作不能被挤掉。
- 项目管理保留项目列表 / 项目详情双栏，空间不足时保留可直接选择的图标列表。
- 概览指标使用蓝 / 青绿 / 琥珀浅色底，数值和说明有明确层级。
- 字体使用系统字体和中英文回退，不添加依赖在线下载的字体。
- 操作和页面顺序不变，表单保存、命令运行、控制台与原生窗口行为不在本次调整范围内。

## 回归检查

- 浅色与深色，960×640、960×720、1280×800、1440×1000、1920×1080。
- 正文及主要语义前景 / 背景对比度不低于 4.5:1。
- 关键页面放大字体、减少动态效果和键盘焦点可用。
- 预览截图使用测试数据，位于 build/theme-previews，不提交用户项目路径、令牌等真实数据。
