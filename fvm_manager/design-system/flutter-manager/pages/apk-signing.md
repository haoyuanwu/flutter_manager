# APK 签名工作流

- “从项目获取 APK”复用产物中心扫描，允许选择具体项目、版本和路径，不再从固定目录直接取最新 APK。
- 产物中心仅对 APK 提供“使用此 APK 签名”；送入待签名列表后自动选中。
- 签名必须先生成独立产物并通过 apksigner 校验，再询问源文件处理方式。即使输出目录与源目录相同，也不能提前覆盖源文件。
- 弹窗明确区分“保留原文件”和“覆盖源文件”；关闭弹窗等价于保留。批量任务只处理签名成功的文件。
- 覆盖前在源目录保存 `.original-时间戳.bak` 备份；覆盖失败保留独立签名产物，不能报告源文件已覆盖。
- “以后不再提示”与上次选择单独持久化，不与包含密码的签名配置混存；缺失或损坏时恢复“每次询问、默认保留”。
- APK 签名、应用签名页面的设置图标均跳转到设置页 APK 签名模块，滚动到源文件处理选项并短暂高亮，支持减少动画。
