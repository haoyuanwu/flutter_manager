# Flutter Manager v1.2.6

## 新增与优化

- 项目列表自动读取项目 Logo，找不到时显示 Flutter Logo。
- 收起项目列表后显示可滚动的 Logo 列表，支持直接切换项目。
- MCP 页面精简为本机服务、一键接入 AI 和手动配置。
- 一键接入自动准备 MCP Server、Skill 和命令指南，复制后可交给本机 AI 完成配置与只读连接验证。
- Skill 新增命令选择指南，区分热重载、热重启、原生改动后重新运行，以及依赖和资源变化的处理方式。

## macOS 安装包

下载 DMG，打开后将 Flutter Manager 拖入 Applications。

- 应用版本：1.2.6（build 12）。
- 包含 Apple Silicon（arm64）和 Intel（x86_64）架构。
- 支持 macOS 12.0 及更新版本。
- 此包未使用 Developer ID 签名，也未进行 Apple 公证。

本次仅发布 macOS 安装包。Windows 版本需要 Windows 构建环境，未在 macOS 上交叉构建。
