# v1.2.7

1. 新增 Debug / Release 运行模式，默认 Debug，重新运行沿用当前项目选择；Release 模式禁用热重载和热重启。
2. 优化项目管理页运行区域，设备与模式分组，常用操作与辅助工具分区，窄窗口自动换行。
3. 重新运行、构建和自定义构建工作流开始前清空对应打印台，保留其他标签输出。
4. 独立控制台手动结束运行后自动关闭窗口；停止失败或超时时保留窗口并提示。
5. macOS 关闭本软件全部窗口后隐藏 Dock 图标，保留托盘和后台任务，重新打开主界面时恢复。
6. 完善版本化产物、Flutter 启动锁解除、运行模式和控制台交互的回归测试。

应用版本：1.2.7（Build 13）。提供 Apple Silicon（arm64）、Intel（x86_64）两个 DMG，适用于 macOS 12.0 及以上。

安装方式：打开对应架构的 DMG，将 Flutter Manager 拖入 Applications。安装包使用临时签名，未进行 Apple Developer ID 签名或公证。本次不发布 Windows 安装包。
