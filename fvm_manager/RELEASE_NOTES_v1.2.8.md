# v1.2.8

1. 优化桌面界面并新增项目依赖管理
2. 支持创建 Flutter 项目、搜索添加与删除依赖，确认后自动执行 Pub Get
3. 支持跟随系统切换明暗主题，统一页面布局、卡片对齐和侧边栏悬停提示
4. 修复 Windows 打开目录和网页误报，完善 FVM 路径选择、缓存与托盘交互
5. 改进 MCP 服务运行状态、端口冲突提示及重试入口
6. 提供 Windows x64 安装包，完善独立构建、断点续传和下载校验脚本

应用版本：1.2.8（Build 14）。提供 Apple Silicon 和 Intel 两个 DMG。

安装包使用临时签名，未进行 Apple Developer ID 签名或公证。
