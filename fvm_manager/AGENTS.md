# 应用目录 AI 工作指引

- 本目录属于上级 `flutter_manager` 仓库，必须同时遵循上级 `../AGENTS.md`。
- 打包、发布、上传或补传前，先读 `scripts/RELEASING.md` 与上级的“AI 发布流程：优先使用已有脚本”。
- 优先使用 `scripts/release.py`、`scripts/package_windows_release.ps1` 和既有 GitHub Actions，不重新拼装发布流程，不重复 CI 已完成的测试、构建、附件下载校验。
- 版本号需用户确认，提交说明用中文，Release 标题仅版本号，更新说明使用编号列表；等待脚本/CI 确认发布完成后给出链接。
